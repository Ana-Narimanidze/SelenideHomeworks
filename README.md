# Selenide Homeworks

## Project Overview

This repository contains homework projects completed during my QA Automation learning journey.

The project focuses on UI automation testing using Java, Selenide, TestNG, and Allure Report. It follows the Page Object Model (POM) design pattern to keep the test code organized, reusable, and easy to maintain.

---

## Key Features

- UI automation testing
- Page Object Model (POM)
- Reusable Page Objects
- Reusable test methods
- TestNG test execution
- Allure reporting
- Clean project structure

---

## Technologies

| Technology | Purpose |
|------------|---------|
| Java | Programming Language |
| Maven | Build and Dependency Management |
| Selenide | UI Test Automation |
| Selenium WebDriver | Browser Automation |

---

## Project Structure

```text
src
├── pages
├── tests
├── steps
└── utils
```

- **pages** – Page Object classes
- **tests** – Test classes
- **steps** – Reusable test steps
- **utils** – Helper classes

---

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Ana-Narimanidze/SelenideHomeworks.git
```

### Install dependencies

```bash
mvn clean install
```

### Run all tests

```bash
mvn clean test
```

---

## Generate Allure Report

```bash
allure serve target/allure-results
```
